# Smok brand assets

The four supplied PNGs are preserved unchanged under `assets/`.

| File | Intended use |
| --- | --- |
| `dragon_cli.png` | Prompt emblem, future app icon and favicon |
| `dragon_logo.png` | Profile image and README header |
| `dragon_mascot_512.png` | GUI avatar and smaller mascot placement |
| `dragon_mascot.png` | Full-resolution mascot source |

| Color | Hex |
| --- | --- |
| Charcoal | `#1A1A1F` |
| Ember | `#E8562A` |
| Deep ember | `#C2410C` |
| Bone | `#D8BFA3` |
| Smoke | `#F3ECE6` |
| Peach | `#FDE4D8` |

The CLI uses Ember, Bone, Smoke, and Charcoal where terminal support permits. The
README uses the supplied profile logo. Raster rendering in the terminal, animated
status expressions, and desktop icons remain part of the later interface work.
